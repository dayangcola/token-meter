AI 额度栏

鼠标移到菜单栏的 AI 图标上，稍作停留即可查看四家额度。点击图标或图钉固定面板，移出自动关闭；固定后再次点击图标可收起。右键图标可刷新或退出。

连接账号

  • Codex：读取本机 codex 的登录。未登录时在终端运行 codex login，再点「读取」。
  • Claude：读取本机 Claude Code 的登录。点「读取」后 macOS 会弹出钥匙串提示。注意：点「始终允许」等于授权系统的 security 工具，此后本机任何程序都能读到这份登录；介意请只点「允许」。
  • Grok：读取本机 grok 的登录。在终端运行 grok login，再点「读取」。
  • Gemini：读取本机 Antigravity CLI 的登录。在终端运行 agy 完成登录，再点「读取」。

本工具不读取浏览器。如果本机尚无对应 CLI 登录或平台调整接口，卡片会保留连接提示，不会编造额度。

读懂面板

  • 进度条和百分比表示剩余额度。小于 20% 变黄，小于 10% 变红。
  • 各个时间窗口单独显示。每家名字右侧是上次成功读取的时间。
  • 读取失败保留上次结果并标记；过了重置时间要等新数据确认，不会自动把它改为 100%。
  • 默认每 5 分钟刷新，可在齿轮菜单关闭。认证失败后等待你手动重新连接。
  • 每个平台只显示本机当前账号；不包含 ChatGPT 聊天额度。
  • Claude 只显示 5 小时和每周；Gemini 只显示 Gemini 5 小时和 Gemini 4 Argon 每周。

数据留在本机

本工具不建立云服务，不上传你的会话或聊天记录；仅调用平台额度接口。原始响应不写日志，临时文件以私有权限创建并在读取后删除。程序不使用重置券、不自动充值、不切换账号。

读取组件：CodexBar 0.84.0（MIT）。本机自签名构建，适用于 Apple Silicon、macOS 14 及以上。
